The purpose of this choice is to let the user create a brand new test (assessment). Once a test is created it can be assigned to one student or to multiple groups of students separately, such as section 3 of Mrs. Smith’s Algebra class and section 2 of Mr. Jones Algebra class. Assigning students to a test is known as an Administration of the test. Assigning students to a test is a different process than creating a test and is done under the Administer Assessment tab. If there is an assessment (test) in the system that you would like to use select the Manage Assessments tab and make a copy. If you would like to add questions into the system for later use select the Question Bank tab. For more information please refer to the help documents.
You first must have an assessment (test) in the system before you can give the test to students. Giving the test is known as “administering” the test. If the desired test does not exist, the user may start with the tab Create New Assessment or make a copy of an existing assessment, from the tab Manage Assessments. The purpose of the tab Administer Assessment is to create an assessment administration which is the process of assigning students to one or more separate and distinct administrations of the same assessment which provides the ability to compare various groups of students that have taken the same test but in separate groups. For more information please refer to the help documents.
